# AI Usage Policy

This policy applies to all contributors of this Minecraft Resource Pack project, which is licensed under the GNU General Public License v3.0 (GPLv3).

## 1. Project Vision

This project is __a Minecraft Resource Pack__ committed to hand-crafted artistry and community-driven creativity. We believe that human touch creates the most meaningful player experiences. At the same time, we embrace technology that empowers creators to work more efficiently.

## 2. Core Principle: Human Creativity First

All final visual and audio assets must be substantially created, edited, and approved by humans.

AI tools are welcome as assistants, but not as replacements for artistic decision-making.

## 3. Encouraged: AI-Assisted Workflows

We actively encourage the use of AI to enhance productivity in non-creative or preparatory tasks.

### 3.1 Approved Use Cases

| Category | Examples | Notes |
|----------|----------|-------|
| Code and Configuration | GitHub Copilot, Cursor, or LLMs for writing .mcmeta files, JSON configurations, Python scripts, build tools | Always review and test AI-generated code |
| Workflow Automation | AI for batch renaming, format conversion, palette extraction, or documentation generation | Ensure outputs are verified before use |
| Creative Brainstorming | Using AI to generate mood boards, color palette suggestions, or conceptual sketches | Must be transformed significantly by human artists |
| Reference Generation | AI-generated images used only as visual references for lighting, composition, or anatomy | Final assets must be drawn from scratch |
| Writing and Documentation | Drafting README files, code comments, translation assistance, or wiki content | Human review required for accuracy and tone |

### 3.2 Safe Harbor Clause

If you use AI only in the process (for example, generating a rough sketch that you completely redraw), you do not need to declare it. Only the final submitted asset matters.

## 4. Prohibited: AI-Generated Final Assets

To comply with GPLv3 licensing requirements and maintain artistic quality, the following are not permitted.

### 4.1 Visual Assets

- Textures, models, GUI elements, fonts, or promotional art directly output by AI without substantial human modification.
- AI upscales that are not manually pixel-perfected afterwards.
- Assets where the core creative expression (composition, detail, style) is determined by AI.

### 4.2 Audio Assets

- Music, sound effects, or ambient audio composed or synthesized primarily by AI.
- AI voice cloning or synthetic voiceovers without explicit licensing clearance.

### 4.3 GPLv3 Compliance Considerations

- GPLv3 requires that all distributed works be freely modifiable and redistributable under the same license.
- AI-generated content may have unclear copyright status or licensing terms, creating legal uncertainty for downstream users.
- By ensuring all assets are human-created, we guarantee the project remains fully compliant with GPLv3's freedom principles.

## 5. Submission Guidelines

### 5.1 Pull Request Checklist

When submitting a Pull Request, please confirm the following:

- [ ] I confirm that all visual and audio assets in this PR are substantially created by humans.
- [ ] I have reviewed any AI-assisted code or configurations for correctness.
- [ ] If using AI-generated references, I have transformed them significantly.

### 5.2 Verification Process

- Maintainers may request work-in-progress files (for example, .psd, .aseprite, or project files) to verify human authorship if concerns arise.
- False declarations (claiming AI assets as human-made) are treated as serious violations.

## 6. Enforcement and Community Trust

| Scenario | Action |
|----------|--------|
| Honest mistake (for example, contributor did not realize a tool was AI-based) | PR closed with constructive feedback; no penalty |
| Perfunctory AI submission (low-effort, clearly AI-generated) | PR closed unconditionally; warning issued |
| Repeated or deliberate violations | Temporary or permanent restriction from contributing |
| Disputed decision | Open a respectful discussion in GitHub Issues for community review |

## 7. Quick Reference Table

| Asset or Task | AI Generation | AI Assistance | Human Creation Required |
|---------------|---------------|---------------|------------------------|
| Block or Item Textures | Prohibited | Allowed (reference or brainstorming) | Required for final pixel art |
| Entity Models and Animations | Prohibited | Allowed (pose suggestions) | Required for final modeling |
| GUI or UI Elements | Prohibited | Allowed (layout ideas) | Required for final design |
| Music and Sound Effects | Prohibited | Allowed (mixing tools, transcription) | Required for final composition |
| .mcmeta or JSON Configs | Allowed | Allowed | Review required |
| Build Scripts or Utilities | Allowed | Allowed | Review required |
| Documentation or Comments | Allowed | Allowed | Review required |
| Promotional Screenshots | Prohibited | Allowed (editing tools) | Required for final composition |

## 8. Questions and Clarifications

If you are unsure whether a specific AI tool or workflow is acceptable:

1. Review this policy document first.
2. Ask in a GitHub Discussion before submitting your contribution.
3. When in doubt, prioritize human creation – we value your artistic voice.
